
# AtmoSync: Micro-Climate Arbitrage Analytics

## Project Overview

AtmoSync is a Python-based Data Analytics project that
collects and analyzes weather information from multiple
geographical locations.

The project aims to identify differences in local weather
conditions and generate meaningful climate insights.

## Objectives

- Collect weather data using Open-Meteo API.
- Monitor multiple geographical locations.
- Clean and preprocess weather datasets.
- Analyze temperature, humidity, rainfall and wind speed.
- Compare weather patterns across cities.
- Develop an interactive analytics dashboard.
- Identify potential micro-climate opportunities.

## Technologies Used

- Python
- Pandas
- NumPy
- Requests
- Streamlit
- Plotly
- Open-Meteo API

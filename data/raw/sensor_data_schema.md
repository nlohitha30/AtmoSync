# AtmoSync - Sensor Data Schema

| Field | Description | Example |
|---|---|---|
| container_id | Container ID | CONT001 |
| commodity | Product name | Avocado |
| temperature_c | Temperature in Celsius | 8.5 |
| humidity_pct | Humidity percentage | 75 |
| vibration | Vibration value | 0.2 |
| timestamp | Reading date and time | 2026-11-10T20:00:00Z |

## Purpose
This common format is used by data collection,
data cleaning, and analysis modules.

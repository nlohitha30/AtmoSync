# AtmoSync - Final Project Validation Checklist

## 1. Python Application Validation
- Verify Python modules compile successfully.
- Execute unit tests using pytest.
- Check sensor data validation.

## 2. Data Pipeline Validation
- Verify weather data collection.
- Check IoT sensor data processing.
- Validate cleaned datasets.

## 3. Kafka Integration
- Verify Kafka broker connectivity.
- Check sensor data producer and consumer.
- Confirm messages reach the correct topic.

## 4. Snowflake and dbt
- Verify Snowflake database connectivity.
- Check sensor data loading.
- Execute dbt models and tests.

## 5. Dashboard Validation
- Verify Streamlit dashboard startup.
- Check KPI cards and sensor monitoring.
- Verify temperature, humidity and vibration charts.
- Check commodity analytics and arbitrage calculations.

## 6. Commodity Analytics
- Verify commodity price dataset.
- Check summary calculations.
- Verify market comparison chart generation.

## 7. Final GitHub Review
- Review project documentation.
- Verify merged team contributions.
- Check repository status and latest commits.

## Conclusion
This checklist is intended to support final integration and validation of the AtmoSync project before its final review.
